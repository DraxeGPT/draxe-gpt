## 🚀 Inicio rápido

```bash
git clone https://github.com/DraxeGPT/draxe-gpt.git
cd draxe-gpt && npm install
cp .env.example .env      # Windows: copy .env.example .env
npm run dev
```

Completa `.env` con tu token y tus IDs. Detalles, variables e intents en la [guía rápida](docs/basico/guia-rapida.md).
> 🔒 Nunca subas `.env` ni compartas tu token.
