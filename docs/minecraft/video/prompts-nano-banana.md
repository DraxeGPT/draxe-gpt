# Video tutorial animado: «Crea tu servidor DraxeCraft Network»

**Flujo:** Nano Banana (generación de imágenes) crea los fotogramas de cada escena con el mismo estilo y personaje. Luego se animan con una herramienta de imagen a video (por ejemplo Veo, Runway, Kling o Canva) y se unen con la voz en un editor (CapCut, DaVinci). Nano Banana **no** hace video por sí solo.

**Formato:** 16:9, 1080p, ~3 min, 10 escenas de ~15–20 s. Idioma: español de México.

## 1. Bloque de estilo (pégalo al inicio de CADA prompt)
```
Estilo: ilustración 3D estilizada tipo voxel/low-poly, colores vivos, fondo oscuro azul medianoche con acentos azul violeta #5865F2, brillo suave, composición limpia 16:9, espacio libre abajo para subtítulos. Sin texto legible incrustado salvo el indicado, sin marcas ni logotipos de terceros, sin personajes con derechos de autor.
```

## 2. Personaje guía (genera primero y reutiliza como imagen de referencia)
```
Personaje original "Draxe": mascota robot cúbico pequeño, cuerpo azul violeta, pantalla-cara con ojos de rayo amarillo ⚡, antena corta, estilo voxel amigable. Vista frontal, fondo liso, pose neutra. Mantener idéntico diseño en todas las escenas.
```

## 4. Prompt de animación (imagen a video, por escena)
```
Anima suavemente la imagen: movimiento de cámara lento (dolly in), partículas y brillo sutiles, el personaje parpadea. Mantén el estilo y colores exactos. 5 a 8 segundos, sin cortes, sin texto nuevo.
```

## 5. Negativos / cuidados
- No pedir ni incluir el logotipo, personajes o capturas oficiales de Minecraft, Mojang, Geyser u otras marcas; usar solo bloques genéricos y el personaje original.
- No mostrar IPs, claves, tokens ni el contenido de `secreto-authme.txt`.
- Los textos legibles (nombres) conviene añadirlos en el editor, no en la imagen.

## 6. Voz y música
Voz masculina o femenina neutra, tono cercano, ritmo calmado. Música instrumental sin copyright y suave. Subtítulos en español.

## 7. Prompt maestro (una sola petición)
```
Crea 10 imágenes 16:9 consistentes para un tutorial animado sobre montar un servidor de Minecraft multi-servidor. Usa el estilo y el personaje "Draxe" descritos. Escenas: [pega la tabla de la sección 3]. Mantén colores, personaje y composición idénticos en todas.
```
