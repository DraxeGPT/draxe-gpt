# Comandos

Prefijo por defecto: `d!` (configurable con `PREFIX`).

| Comando | Descripción | Permisos |
|---------|-------------|----------|
| `d!help` | Centro de ayuda interactivo | Todos |
| `d!userinfo` | Información de un usuario | Todos |
| `d!serverinfo` | Información del servidor | Todos |
| `d!botinfo` | Información del bot | Propietario |
| `d!host` | Monitor del host | Propietario |
| `d!suggestion <texto>` | Sugerencia con votación | Todos |
| `d!invite` | Enlace de invitación | Todos |
| `d!8ball <pregunta>` | Bola 8 mágica | Todos |
| `d!ship @a @b` | Compatibilidad entre dos usuarios | Todos |
| `d!setlogchannel [#canal\|off]` | Configura el canal de registro | Gestionar servidor |
| `d!setannounce <tipo> #canal [@rol]` | Configura dónde se envían los anuncios | Gestionar servidor |
| `d!announce <tipo> …` | Lanza un anuncio con embed | Propietario |

**En desarrollo:** confesiones, moderación y tickets (ver [hoja de ruta](../../README.md#hoja-de-ruta)).
